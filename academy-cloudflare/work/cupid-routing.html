01 / VERIFIED COMPONENTS

Architecture and decision boundaries

Ingest

A dedicated Gmail trigger captures messages, then Edit Fields normalizes the incoming request.

Classify

Gemini with a structured output parser returns a department and supporting fields.

Route

An n8n Switch chooses a department, followed by Gmail and Slack actions.

This workflow includes a duplicate-guard lookup and a processed-state update. Its existing execution screenshots and narrated walkthrough support a portfolio demonstration, but the current public repository does not include a sanitized executable n8n export.

03 / ENGINEERING FOLLOW-UP

How this becomes stronger

Control

Add a deterministic confidence gate with explicit ambiguous-input behavior.

Idempotency

Use an atomic unique record before notifications to prevent concurrent duplicate sends.

Reliability

Reconcile partial failures, capture dead-letter events and alert after final retry.

Proof

Publish a sanitized workflow export, test scenarios, expected decisions and an evidence index.

These are proposed remediation steps. They are not represented as already implemented.

04 / ACADEMY APPLICATION

What learners can reproduce

Start with a deterministic router before adding AI classification. Compare the model's suggested department against a validated list, avoid automatic external actions when classification is uncertain, and test retry and duplicate-delivery scenarios.
